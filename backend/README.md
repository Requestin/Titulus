# `backend/` - control plane API + WebSocket hub

Stack:

- Node.js 20+, ESM
- Express 4 + `express-ws`
- SQLite (`better-sqlite3`, WAL)
- `multer`, `ajv`, `ajv-formats`

## Main modules

- `src/index.js` - app bootstrap, middlewares, routing, static assets.
- `src/db.js` - schema + DAO layer (`templates`, `channels`, `rundowns`, `settings`, `on_air`, `license_state`, `users`, `sessions`, `tenants`, `audit_events`).
- `src/onair.js` - in-memory on-air mirror + persistent replay-on-connect logic.
- `src/media.js` - upload ingest/transcode pipeline.
- `src/auth.js` - token auth/session helpers and role middleware.
- `src/audit.js` - mutating API audit logging middleware with redaction.
- `src/routes/*` - modular API routes (`auth`, `templates`, `channels`, `rundowns`, `uploads`, `license`, `billing`, `audit`, `ws`).

## API surface (high level)

- Auth: `/api/auth/login`, `/api/auth/logout`, `/api/auth/me`, `/api/auth/users`
- Templates/channels/rundowns/settings/onair
- Uploads: `/api/uploads`, `/api/uploads/jobs/:id`
- License: `/api/license/*`
- Billing: `/api/billing/entitlements`, `/api/billing/hook`
- Audit: `/api/audit/events`
- WS: `/ws/control`, `/ws/renderer`

`/ws/control` is auth-protected and requires a valid token (query/header).
